# 🔥 ZYMORE - HYBRID SOCIAL DIGITAL MARKETPLACE

## 🌐 COMPLETE PLATFORM OVERVIEW & DETAILED DESCRIPTION

---

# 🪞 ZYMORE KYA HAI?

**ZYMORE** ek **Hybrid Social Digital Marketplace** hai jo **Instagram, Amazon, OLX, ChatGPT aur YouTube** ki features ko ek platform mein combine karta hai. Yeh ek aisi app hai jahan:

- 📱 **Social Media** - Instagram jaisi feel
- 🛒 **Shopping** - Amazon/OLX jaisa marketplace
- 🤖 **AI Assistant** - ChatGPT jaisa smart chatbot
- 💬 **Chat System** - Direct buyer-seller communication
- 💰 **Earning** - Ad monetization system

---

# 🎯 ZYMORE KA MISSION

> **"Ek Platform, Sab Kuch"**

ZYMORE ka mission hai ki ek hi app mein users ko:
1. **Social Connection** - Apni community ke saath judna
2. **Buying & Selling** - Digital aur physical products
3. **AI Support** - Smart assistant for help
4. **Earning Opportunity** - Ads dekh kar coins kamana

---

# 🏗️ ZYMORE KYA BAN RAHA HAI?

ZYMORE ek **Complete Application** hai jo **PWA (Progressive Web App)** ke form mein ban raha hai. Yeh mobile, tablet aur desktop par seamlessly kaam karega.

├── Events: auth, theme, notifications, posts, products, chat, ai, ads
├── Subscribers: All components
└── Purpose: Decoupled communication

```
📦 Store (Central State)
├── auth: { user, isLoggedIn, isLoading, error }
├── theme: { mode: 'light' | 'dark' }
├── posts: { items, isLoading, error }
├── stories: { items, isLoading, error }
├── products: { items, isLoading, error }
├── categories: { items, isLoading, error }
├── notifications: { items, unread, isLoading }
├── chat: { chats, activeChat, messages, isLoading }
├── ai: { messages, questionCount, isLoading }
├── ads: { bannerAd, rewardedAd, coins }
├── feed: { algorithm, isLoading, error }
├── profile: { user, followers, following, isLoading }
└── settings: { preferences, isLoading }
```

```
🚀 Router (SPA Routing)
├── Routes: 20+ routes
├── History: Browser history API
├── Guards: Auth protection
├── Params: Dynamic routing
└── Transitions: Smooth page transitions
```

### App Controller
```
📱 App (Main Controller)
├── Initialize: Firebase, Services, Store

├── PWA: Service worker registration
└── Performance: Monitoring
```
